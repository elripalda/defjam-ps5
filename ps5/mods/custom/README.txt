Put your own versions of these pictures in this folder, with these names:

  title-logo.png          the Def Jam logo on the title and attract screens (512x128)
  story-logo.png          the logo used in Story mode (512x128)
  console-small.png       the Xbox console on the loading and save screens (128x64)
  autosave-panel.png      the autosave warning, console picture included (512x256)
  controller-diagram.png  the controller on the Controller Setup screen (512x256)

Bigger is fine as long as the shape stays the same (2048x512 for a logo, say).
Keep transparent areas transparent. The game uses them the next time it starts.

Installing a new build copies this README and manifest.ini again but leaves
your pictures alone. Keep a copy of them somewhere else anyway.
